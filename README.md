# DaSHe Books

The canonical public hostname is `dashebooks.com`. Every catalogue title
automatically receives a permanent page at `/<hyphenated-book-title>`.
Run `scripts/build-static.sh` before packaging a deployment so direct visits to
all current book routes are emitted into `dist/`.

Official bookstore for author Kehinde Akinlolu OJO. This is a dependency-free, motion-led static site designed for ChatGPT Sites hosting.

The experience includes 33 optimized book covers, a 3D featured carousel, a continuous cover stream, catalogue search and filters, accessible quick-view dialogs, touch gestures, keyboard controls and reduced-motion support.

## Local preview

Open `index.html` directly, or run any static HTTP server from this directory.
